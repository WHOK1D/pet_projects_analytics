# Анализ результатов A/B-тестирования интернет-магазина BitMotion Kit

## Цель
Оценить результаты A/B-теста новой версии интерфейса сайта BitMotion Kit, чтобы определить, приводит ли упрощение интерфейса к статистически значимому росту конверсии зарегистрированных пользователей в покупателей в течение 7 дней после регистрации как минимум на 3 п.п.

## Данные
- `ab_test_participants.csv` — участники тестов: `user_id`, `group`, `ab_test`, `device`.
- `ab_test_events.zip` — события 2020 года: `user_id`, `event_dt`, `event_name`, `details`.

## Проделанные шаги
1. Загрузка и первичный анализ данных.
2. Проверка корректности A/B-теста:
   - исключение пересечений пользователей между тестами (446 пользователей);
   - проверка равномерности распределения по группам (A: 5277, B: 5127; разница ~2.9%);
   - фильтрация событий: оставлены только события в течение 7 дней после регистрации;
   - проверка равномерности распределения по устройствам (успешно);
   - проверка достаточности размера выборки (требуется 3762 на группу, фактически больше);
   - расчёт конверсии в покупку.
3. Проверка статистической значимости с помощью z-теста пропорций (односторонний).
4. Интерпретация результатов.

## Результаты
- Конверсия в покупку: группа A = 27.55%, группа B = 29.28%.
- Относительная разница: +6.28%, абсолютная: +1.73 п.п.
- z-тест пропорций: p-value = 0.0257 (при α = 0.05).
- Нулевая гипотеза отклонена: конверсия в группе B статистически значимо выше, чем в группе A.
- Однако реальный MDE (1.73 п.п.) ниже предполагаемого (3 п.п.).

## Выводы
- Новый интерфейс статистически значимо повышает конверсию, но эффект меньше ожидаемого.
- Практическая значимость для бизнеса не подтверждена: рост на 1.73 п.п. может не оправдать затраты на разработку и внедрение.
- Тест обладает достаточной мощностью, так как выборка превышает требуемую.
