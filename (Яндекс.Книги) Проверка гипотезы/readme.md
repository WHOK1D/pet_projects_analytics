# Проверка гипотезы для сервиса Яндекс.Книги

## Цель
Проверить гипотезу о том, что пользователи из Санкт-Петербурга более лояльны и проводят в среднем больше времени за чтением и прослушиванием книг, чем пользователи из Москвы.

## Данные
Выгрузка из БД Яндекс.Книги `yandex_knigi_data.csv`:
- `city` — город пользователя
- `puid` — идентификатор пользователя
- `hours` — сумма часов чтения и прослушивания

## Проделанные шаги
1. Загрузка и первичный анализ данных.
2. Проверка на дубликаты и пропуски.
3. Обнаружение и исключение пересекающихся пользователей между городами (дубли по `puid`) — потеря ~2.86% данных.
4. Анализ выбросов и распределения метрики `hours`.
5. Проверка гипотезы с помощью t-теста Уэлча (односторонний, альтернатива: среднее в СПб > среднее в Москве).
6. Формулировка аналитической записки.

## Результаты
- Средняя активность: Москва — 10.848 ч, Санкт-Петербург — 11.264 ч.
- Разница средних: +0.416 ч в пользу СПб.
- t-тест Уэлча: p-value = 0.33 (при α = 0.05).
- Нулевая гипотеза не отклонена: статистически значимых различий не обнаружено.

## Выводы
- Данные не подтверждают гипотезу о том, что пользователи из СПб в среднем активнее москвичей.
- Различие в 0.416 ч может быть случайным.
- Распределение `hours` сильно скошено вправо, присутствуют выбросы, что снижает мощность теста.
- Исследование является сравнением двух реальных городов, а не A/B-тестом, поэтому причинно-следственные выводы делать нельзя.

## Рекомендации
- Учесть категориальные признаки пользователей (возраст, жанровые предпочтения, устройство и т.п.).
- Увеличить выборку или применить более робастные методы (бутстрэп, преобразование логарифмом).
- Рассмотреть другие метрики лояльности (retention, частота сессий, LTV).
- Провести контролируемый A/B-тест для проверки влияния города на активность.
