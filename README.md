# Проекты по анализу данных

Автор: **Казанцев Павел**

Репозиторий содержит проекты по анализу данных, статистической проверке гипотез, оценке результатов A/B-тестирования, разведочному анализу данных (EDA) и разработке дашбордов.

---

## Проекты

| Название проекта | Цель | Стек |
|---|---|---|
| Проверка гипотезы для сервиса Яндекс.Книги | Проверить гипотезу о том, что пользователи из Санкт-Петербурга более лояльны и проводят в среднем больше времени за чтением и прослушиванием книг, чем пользователи из Москвы | Python 3.13, pandas, numpy, matplotlib, scipy.stats, jupyter_black |
| Анализ результатов A/B-тестирования интернет-магазина BitMotion Kit | Оценить результаты A/B-теста новой версии интерфейса сайта и определить, приводит ли упрощение интерфейса к статистически значимому росту конверсии зарегистрированных пользователей в покупателей в течение 7 дней после регистрации как минимум на 3 п.п. | Python 3.13, pandas, numpy, matplotlib, scipy.stats, statsmodels, jupyter_black |
| EDA по данным о ДТП (с картами) | Повысить безопасность на дорогах: выявлять реальные причины ДТП, оценивать развитие инфраструктуры и помогать разрабатывать программы по снижению аварийности. Заказчик также ожидает рекомендаций по улучшению качества собираемых данных. | Python, pandas, numpy, matplotlib, seaborn, folium (или plotly) |
| EDA Рынок стартапов | Исследование динамики и структуры финансирования стартапов, а также ответы на вопросы, важные для оценки инвестиционных стратегий. | Python, pandas, numpy, matplotlib, seaborn |
| EDA Заведения общественного питания Москвы | Провести исследовательский анализ данных (EDA) заведений общественного питания Москвы, выявить ключевые характеристики и факторы, влияющие на рейтинг заведений. | Python 3, Jupyter Notebook, pandas, matplotlib, seaborn, phik, numpy, re |
| A/B-тестирование нового алгоритма рекомендаций | Проверить, улучшает ли новый алгоритм рекомендаций вовлечённость пользователей в первые сессии, и оценить корректность проведения A/B-теста. | Python, pandas, numpy, scipy.stats, statsmodels, matplotlib |
| Разработка дашборда для благотворительного фонда | Проанализировать динамику активных благотворителей (MAU), retention по когортам пола, средний чек и количество заказов по полу, а также LTV по крупным городам для выработки рекомендаций по удержанию и развитию донорской базы. | Yandex DataLens, SQL |

---

- **Языки и среды:** Python 3, Jupyter Notebook, SQL
- **Библиотеки:** pandas, numpy, matplotlib, seaborn, scipy.stats, statsmodels, phik, re, jupyter_black
- **BI-инструменты:** Yandex DataLens
- **Гео-визуализация:** folium / plotly
