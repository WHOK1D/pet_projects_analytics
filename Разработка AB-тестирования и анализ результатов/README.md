# A/B-тестирование нового алгоритма рекомендаций

## Цель
Проверить, улучшает ли новый алгоритм рекомендаций вовлечённость пользователей в первые сессии, и оценить корректность проведения A/B-теста.

## Этапы работы
1. **EDA исторических данных**  
   Проанализированы уникальные пользователи, регистрации, просмотренные страницы и доля успешных первых сессий (`page_counter >= 4`).
2. **Подготовка к тесту**  
   Рассчитаны размер выборки, мощность и длительность теста.  
   Требуемый размер: **41 040 пользователей на группу**, длительность при текущем трафике: **9 дней**.
3. **Мониторинг A/B-теста**  
   Проверены распределение пользователей, пересечения между группами, равномерность по устройствам и регионам.
4. **Анализ результатов**  
   Сравнены целевая и прокси-метрики, проведены z-тест пропорций и t-тест Уэлча, оценена фактическая мощность теста.

## Ключевые результаты
- В исторических данных доля успешных первых сессий в среднем составляла **~31%**.
- За первые 3 дня теста группы были сбалансированы: разница по числу пользователей — **0.74%**, пересечений нет, распределения по устройствам и регионам совпадают.
- За 20 дней теста набрано:
  - группа A: **15 163** пользователя;
  - группа B: **15 416** пользователей.

| Метрика | Группа A | Группа B | p-value | Вывод |
|---|---:|---:|---:|---|
| Доля успешных первых сессий | 31.57% | 31.47% | 0.578 | нет значимого роста |
| Средняя глубина просмотра первых сессий | 3.0174 | 3.0300 | 0.145 | нет значимого роста |
| Доля первых сессий с ≥2 страницами | — | — | 0.225 | нет значимого роста |

## Выводы
- Новый алгоритм рекомендаций **не показал статистически значимого улучшения** целевой метрики.
- Прокси-метрики также не выявили значимых различий между группами.
- Тест оказался **недостаточно мощным**: фактическая мощность — **~52%**, реальный детектируемый MDE — **~1.31 п.п.** при целевом **0.9 п.п.**
- Для достижения целевой мощности требовалось примерно **32 000 пользователей на группу**, но было набрано меньше.
- Внедрение новой рекомендательной системы по результатам текущего теста **не обосновано**.

## Рекомендации
- Продлить тест до набора ~**32 000 пользователей на группу** или увеличить долю трафика.
- Пересмотреть MDE в сторону увеличения, например до **1.5 п.п.**, при текущем объёме данных.
- Использовать более чувствительные метрики вовлечённости.
- Повторить эксперимент и принять решение о раскатке только после достижения достаточной мощности.
- Сохранить проверки баланса групп, отсутствия пересечений и равномерности распределения по устройствам и регионам.
